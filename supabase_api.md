# FastAPI CRUD API dengan Supabase

Panduan ini membina API FastAPI untuk menyimpan data pengguna dalam database
PostgreSQL yang disediakan oleh Supabase.

## 1. Cipta table `users`

Dalam Supabase, buka **SQL Editor** dan jalankan SQL berikut:

```sql
create table users (
    id bigint generated by default as identity primary key,
    name text not null,
    email text not null unique,
    age integer not null check (age >= 0)
);
```

Supabase menggunakan PostgreSQL sebagai database engine. Database engine ini
tidak boleh ditukar kepada MySQL atau Oracle.

## 2. Ambil credentials Supabase

Pergi ke **Project Settings > API** dan salin:

- **Project URL**
- **Publishable (anon) Key** untuk training atau akses yang dikawal oleh RLS
- **service_role Key** hanya untuk backend yang memerlukan akses penuh

Jangan expose `service_role` key kepada frontend atau commit key ke source
control.

## 3. Simpan credentials dalam `.env`

Cipta fail `.env` dalam folder projek:

```env
SUPABASE_URL=https://your-project.supabase.co
SUPABASE_KEY=your-supabase-api-key
```

Kod API akan membaca fail `.env` secara automatik. Pastikan API key yang
digunakan mempunyai permission untuk mengakses table `users` di bawah polisi
RLS yang dikonfigurasi.

## 4. Install dependency

Jalankan arahan berikut dalam terminal:

```bash
pip install -r requirements.txt
```

Atau install terus dengan arahan ini:

```bash
pip install fastapi "pydantic[email]" supabase uvicorn python-dotenv
```

## 5. Jalankan API

```bash
uvicorn supabase_api:app --reload
```

Buka [http://127.0.0.1:8000/docs](http://127.0.0.1:8000/docs) untuk akses
Swagger UI.

## Endpoint CRUD

| Method | Path | Kegunaan |
| --- | --- | --- |
| `POST` | `/users` | Cipta user |
| `GET` | `/users` | Senaraikan semua user |
| `GET` | `/users/{user_id}` | Dapatkan satu user |
| `PATCH` | `/users/{user_id}` | Kemaskini field yang dihantar |
| `DELETE` | `/users/{user_id}` | Padam user |

Contoh request body untuk `POST /users`:

```json
{
  "name": "John",
  "email": "john@example.com",
  "age": 30
}
```
