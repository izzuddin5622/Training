# FastAPI CRUD API with Supabase

This guide creates a FastAPI service that stores users in a Supabase PostgreSQL database.

## 1. Create the Supabase table

In the Supabase dashboard, open **SQL Editor** and run:

```sql
pip install -r requirements.txt
    id bigint generated by default as identity primary key,
    name text not null,
    email text not null unique,
    age integer not null check (age >= 0)
Create a file named `.env` in the project folder and add the project URL and API key from **Supabase dashboard > Project Settings > API**:
```
```env
SUPABASE_URL=https://your-project.supabase.co

## 2. Install the dependencies

The API loads `.env` automatically. Keep this file out of source control. Do not put a secret service-role key in frontend code. The API key used here must have permission to access the `users` table under the table's RLS policies.

```bash
pip install fastapi "pydantic[email]" supabase uvicorn
```

## 3. Configure Supabase credentials

Copy the project URL and API key from **Supabase dashboard > Project Settings > API**, then set them as environment variables:

```bash
export SUPABASE_URL="https://your-project.supabase.co"
export SUPABASE_KEY="your-server-side-api-key"
```

Keep these values out of source control. Do not put a secret service-role key in frontend code. The API key used here must have permission to access the `users` table under the table's RLS policies.

## 4. Create `supabase_api.py`

Copy the implementation from [`supabase_api.py`](supabase_api.py) into your project.

## 5. Start the API

```bash
python -m uvicorn supabase_api:app --reload
```

Open `http://127.0.0.1:8000/docs` to use the interactive Swagger UI.

## Available endpoints

| Method | Path | Purpose |
| --- | --- | --- |
| `POST` | `/users` | Create a user |
| `GET` | `/users` | List all users |
| `GET` | `/users/{user_id}` | Get one user |
| `PATCH` | `/users/{user_id}` | Update supplied fields |
| `DELETE` | `/users/{user_id}` | Delete a user |

Example request body for `POST /users`:

```json
{
  "name": "John",
  "email": "john@example.com",
  "age": 30
}
```
